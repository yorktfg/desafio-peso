Conectar ao Google Drive

Cole seu Client ID do Google abaixo para salvar os dados no Drive e acessar de qualquer dispositivo.

Como obter o Client ID (gratuito, ~5 min):
1. Acesse console.cloud.google.com
2. Crie um projeto (ou use um existente)
3. Ative a Google Drive API em "APIs e Serviços"
4. Em "Credenciais" → "Criar credencial" → "ID do cliente OAuth"
5. Tipo: Aplicativo da Web. Em "Origens JavaScript autorizadas", adicione o endereço onde o arquivo está aberto (ex: file:// ou o domínio)
6. Copie o Client ID gerado e cole acima.
